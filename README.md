## 📘 Project Description
**AUTOFIGURE-AI** is an intelligent, AI-assisted diagram generator that converts **text or image inputs** into clean, structured, and visually rich diagrams.  
It is designed to help **students, engineers, educators, and professionals** quickly understand and present complex concepts using auto-generated visual diagrams with themes, animations, and smart coloring.

---

## ✅ Core Features  
- ✅ **Text & Image to Diagram Conversion**  
  - Paste text or upload an image → AUTOFIGURE-AI extracts information and builds a diagram.

- ✅ **Supports 6 Professional Diagram Types**
  - **Flowchart**  
  - **ER Diagram**  
  - **UML Class Diagram**  
  - **Use Case Diagram**  
  - **Network Topology Diagram**  
  - **Data Flow Diagram (DFD)**  

- ✅ **AI Diagram Chat**
  - Ask in natural language:
    - *“Explain node 3”*  
    - *“Add an example to this branch”*  
    - *“Make this part simpler”*  
  - The system responds and can update the diagram interactively.

- ✅ **Auto Smart Coloring**
  - Automatically chooses node colors based on:
    - Hierarchy groups  
    - Step categories  
    - Dependencies  
    - Importance  

- ✅ **Diagram Themes (Visual Styles)**
  Built-in themes to change the entire diagram look:
  - **Minimal**  
  - **Neon**  
  - **Cyberpunk**  
  - **Pastel**  
  - **Blueprint**  
  - **TechWire**  
  - **Professional Office**  

- ✅ **Play Animation Mode**
  - Animates the diagram **step-by-step**:
    - Node-by-node highlight  
    - Animated arrows  
    - Zoom and focus transitions  
  - Great for **teaching and revision**.

- ✅ **Multi-Format Export**
  - Download diagrams as:
    - **PNG**  
    - **SVG** (editable)  
    - **PDF** (auto layout)  
    - **JSON** (for re-editing/import)  
    - `.AI` (Adobe Illustrator – planned for future)

- ✅ **Save & Load Diagrams**
  - Save diagrams in local storage  
  - View, load, and manage previously saved diagrams  

- ✅ **Modern UI / UX**
  - Dark & Light mode  
  - Smooth animations using Framer Motion  
  - Professional, elegant, premium design

## 🧠 Diagram Types Overview  

### 1️⃣ Flowchart  
Used for **processes and workflows**:  
- Start / End nodes  
- Process steps  
- Decision diamonds  
- Directional arrows  

### 2️⃣ ER Diagram  
Used for **database and data modeling**:  
- Entity nodes (tables)  
- Attributes  
- Relationships  

### 3️⃣ UML Class Diagram  
Used in **software design**:  
- Class boxes (name, attributes, methods)  
- Associations between classes  

### 4️⃣ Use Case Diagram  
Used to represent **system interactions**:  
- Actors (users/external systems)  
- Use cases (system functions)  
- Relationships (includes, extends, associations)  

### 5️⃣ Network Topology Diagram  
Used in **computer networks**:  
- Routers, switches, servers, clients  
- Connectivity and topology of the network  

### 6️⃣ Data Flow Diagram (DFD)  
Used in **system/data flow modeling**:  
- Processes  
- Data stores  
- External entities  
- Data flows
